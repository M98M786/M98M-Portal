📌 Golden Rules — Har Chat Se Pehle
Golden rules
  1. Order of operations: pehle WRITTEN APPEAL (FA-1 / appeal form / VA-series) → decline ho to phir chat — aur chat ka pehla block hamesha: appeal date + decline date + reference. Appeal ke baghair "removal" chat = "submit an appeal first" ka deflection.
  2. Blocks EK EK kar ke bhejo — poora script kabhi paste nahi.
  3. Sirf wohi facts jo tracking/records genuinely support karein — ek false claim poore account ke appeals kharab karta hai.
  4. Har chat ka CLOSE block mandatory (U-6): written confirmation + reference number + "no defect" confirmation.
  5. Max ~10 orders per session. Strong cases pehle.
  6. Teen-qadam ladder: Ask 1 → fail → Ask 2 (usi evidence par narrow re-ask) → fail → Ask 3 (manual review + record + reference number). Ask 3 ke baad behes band — U-6 close karo; agla rasta written appeal ya 2-3 din baad naya agent, naye hook ke saath.
  7. Written appeal pehle (FA-1 / VA-series), chat second opinion — dono mein wohi ek hook, kabhi contradict nahi. Ek appeal = ek strongest hook.
  8. British English, polite, calm — agent se kabhi behes nahi. Agent rude ho to bhi tone same; politely close karo, new chat mein doosre agent se try karo.
  9. Chat ke baad turant Saved Msgs mein log karo: date, account, agent name, reference number, orders, outcome — aur screenshot save karo.
Kab submit nahi karna (late shipment)
  • Tracking sirf upload hui, acceptance scan handling time ke andar nahi.
  • Delivery Latest EDD ke baad hui.
  • Koi scan record hi nahi. Upload date akela kisi path mein qualify nahi karta.
  • JJD-prefix tracking = usually Evri (Yodel nahi) — courier name confirm kar ke bolo.
Kab chat / appeal bilkul nahi karni (violations)
  • Signal/RFID copying devices, branded replica items, ya koi bhi clearly restricted product — appeal karne se account par review attention aati hai. Removal accept karo, delisted rakho, aage barho.
Returns & disputes
  • Har return kholte waqt photos/video — box, label, contents. Return mein ghalat/khaali item aaye to CF-7, sirf documented facts ke saath.
  • Dispute khulte hi pehla kaam PD-1: deadline + evidence list + upload route. Deadline miss = automatic loss.
  • Chargeback (CF-6) ki deadline pehle — challenge submit karo, phir chat se evidence note karwao aur protection + fee waiver confirm karo.
Reference number
  • Bina reference number "removal" aksar account par reflect nahi hota. Har chat U-6 close ke sath khatam karo; 48 ghante baad update na ho to FUP-1.
