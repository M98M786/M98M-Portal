Link not working? Use the one-click grabber

Public retrieval services get rate limited and eBay sometimes shows them a bot check. The grabber runs on the eBay page itself, so nothing can block it. Set it up once, use it forever.

  1. Press Copy grabber below.
  2. In your browser, add a new bookmark. Name it Grab eBay.
  3. Where it asks for the address or URL, paste what you copied. Save.
  4. Open any eBay listing and click that bookmark. It copies the details.
  5. Come back here, paste into the box above, press Get details.

Works on any eBay site. It reads only the page you are looking at and sends nothing anywhere — it just copies to your clipboard.

You can also paste a copied eBay page straight into the same box. It works out which one you gave it.

Step 3

eBay keywords

Paste the suggested keyword list from your Promoted Listings campaign. Any size list is fine.

Keyword list

CSV, a copy-paste straight out of Excel or Google Sheets, or a plain one-per-line list. Columns are detected automatically.

Which columns does it understand?

Matched loosely, in any order:

  • Keyword — keyword, search term, term, query, phrase
  • Demand — volume, searches, search volume, demand, impressions
  • Cost — cpc, bid, suggested bid, cost per click, avg cpc
  • Competition — competition, competitiveness, difficulty (High/Medium/Low, 0–1 or 0–100)

No header row and a numeric second column is read as keyword, volume, cpc, competition, and it tells you so. A one-column list is fine — those metrics read N/A and their weight is shared across the rest.

Optional — scoring weights and tier cut-offs

Defaults are tuned for eBay resale. Change these only if the shortlist keeps coming out wrong in the same direction.

Total 100

A keyword must clear both the score and the relevance floor to enter a tier. Nothing is selected to hit a target count — if only 12 keywords are strong, you get 12.

A keyword is dropped when one in a higher tier already covers more than the overlap limit of the same search — that is what keeps the shortlist short. Keywords with the same meaningful words in a different order are always merged.
